# Rogue 32×32ドット絵版

2026-10-02。地図の表示を **文字／イラスト／ドット絵** から選べます。既存の96pxイラストを保持し、新しく生成した32px画像を追加しました。`start.ps1` で起動して「ドット絵」を選ぶか、`http://127.0.0.1:4173/?view=pixels` で開きます。

32pxは表示サイズだけでなく、**各PNGの実寸が32×32**という意味です。太い暗色の輪郭、四角い色のまとまり、少ない色数のファンタジー絵です。

## 画像と表示

- 原作と同じ49表示ID、PNG46枚。地形8・プレイヤー1・アイテム9・魔法検出印1・弾道4・敵26です。弾道4方向は1枚を共有します。
- 各PNGは32×32 RGBA、各画像16色以下、透明度は0または255。床・通路・暗闇は全面不透明、キャラクター・アイテム等の周囲は透明です。
- ドット絵の倍率は100／200／300／400%（32／64／96／128px）の整数倍。イラストの50〜200%表示と文字表示も残しています。
- 最近傍で拡大し、Canvasのバッファ倍率は1か2です。原寸の1画素が4倍表示で正確に4×4画素になることを実Chromeで検証しました。OSやブラウザの非整数倍率による最終表示まで全機種で保証するものではありません。
- 床・通路は上下左右の辺が一致。横壁は左右、縦壁は上下を一致させています。表示済みのセルだけを描画し、敵やアイテムの下地は従来の中立的な床です。
- 斜め弾道は、拡大した絵を回転せず、元の32px格子へ最近傍で回転した一時画像をキャッシュしてから拡大します。輪郭に半透明のぼけを追加しません。

ゲームが読み込む画像は `web/assets/pixels-v2/`、表示IDと画像の対応は[manifest](../web/assets/pixels-v2/manifest.json)にあります。

## 設定・ゲーム本体

表示モードと倍率は、ゲーム用の `rogue-map-display-v1` キーでlocalStorageへ保存します。`web/view-settings.js` が版・モード・整数倍率を検査し、不正なデータは従来のイラスト100%へ戻します。保存領域が禁止されていても、その場の表示切替は使えます。`?view=ascii`／`?view=tiles`／`?view=pixels` は起動時の表示を明示できます。

表示設定はゲームのセーブに含めません。Cロジック、Rust、ABI、Wasm本体、乱数、既存の保存形式は変更していません。Cが既に表示した同じ意味IDから画像を選ぶので、未探索マップ・未鑑定効果・擬態の正体などを追加で示しません。日本語HUD・メニュー・読み上げ用のセル説明も維持しています。画像の不足や未対応記号はエラーになり、通常の画像プレイでASCIIへ自動置換しません。
